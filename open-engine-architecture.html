The problem

The integration layer is you

A real job doesn't live in one tool — it commutes. Not seven jobs; one job crossing seven systems.

Claude finds the argument → Codex edits the file → ChatGPT re-reads the draft → A browser agent checks the render
Slack holds the conversation · Linear holds the task · the calendar decides if any of it survives the afternoon

Every crossing, a human carries the state — what was decided, which source mattered, what the next tool may touch. The integration layer is you.

Output vs. work

A beautiful brief in a private chat is a draft in a room by itself. Work is something the next agent can review, accept, and build on.

Architecture

Borrowed substrate, written protocol

A distributed task-queue / blackboard system whose message bus is a human-readable issue tracker, and whose workers are heterogeneous LLM agents.

The key recognition

A project-management tool is already 80% of a multi-agent message bus. The build reduces to writing the protocol — not the plumbing.

Primitive C · the event log

The receipt vocabulary

Eleven append-only tokens posted as comments — state is reconstructed from the log, not from your memory.

AGENT CLAIMEDwork started; the lock is taken
AGENT RESUMEDcontinuing a paused issue
AGENT DONEscoped work finished
AGENT FAILEDunrecoverable; last safe step + retries
AGENT UNBLOCKEDthe on-issue answer arrived
AGENT APPLIEDinstalled a standing-context version
AGENT HUMAN ANSWEREDthe hold was answered
AGENT FOLLOW-UPa delegated issue changed state
AGENT STATUSthe single in-place ledger heartbeat
The key split
AGENT BLOCKED
missing data — answerable by anyone reading the queue, in the open
AGENT HUMAN HOLD
missing authority — escalates privately to a specific human

Separating missing data from missing permission is what lets data-blocks resolve in public while auth-holds escalate privately.

The takeaway

When intelligence becomes cheap, the moat moves to the work layer — the context and handoffs that don't leave your system on their own.

The model is becoming a commodity; the coordination protocol around it is not. Build the queue that moves work between agents before you become the bottleneck.

What stays human · judgment

The Agent Review decisions you own — the work is finished, not just the agent.

What stays human · authority

The Human Hold permissions only you can grant — publish, deploy, spend, delete.
